## 4. Findings

### Blockers

**B1 — the cross-encoder arm silently omitted `placed_left`, the reference bases and the record's
extent, and its doc comment said the opposite.**
*Raised independently by two agents (reliability+extras, errors+defaults+refactor) — convergent.*

`check_against_the_prototype` compared ten things and named three deliberate exclusions, which
reads as *everything else is compared*. Three fields with a counterpart in the source were not.

**Reproduced in the main checkout before anything was changed.** Two defects planted in the
harness's *own mapping* — the class the second arm exists for, since the round-trip arm carries
such a defect on both sides:

| planted in `as_an_ng_record` | over 74,623 records |
|---|---|
| `mapq_sum + 1` (the author's own control) | killed at record 0 |
| `placed_left + 1` | **passed, clean report** |
| `end: Position(start + span)` — every region a base too long | **passed, clean report** |

The last two were planted together and the run printed a full clean report.

### B2 — eighteen of the twenty-six field comparisons had no test that they could fail.

The reliability agent neutered each comparison in turn — rewriting `assert_eq!(a.x, b.x)` as
`assert_eq!(a.x, a.x)` — and ran the suite. Eight were killed; **eighteen survived with all 23
tests green**, among them the region, the reference bases, the locus kind, `num_obs`, `mapq_sum`
and `placed_left`. The file's own test-module doc says the tests exist to stop exactly that.

### B3 — the branch's CI clippy step has been red since `b0e1a54a`, and H1's report said the
opposite about the mechanism.

`.github/workflows/ci.yml` sets `RUSTFLAGS: -D warnings` job-wide and runs `cargo clippy
--all-targets --all-features -- -D warnings`. That has built `examples/psp_row_stream_roundtrip.rs`
as its own target since the measuring programs were committed, and it fails on two lints.

**Reproduced here, and the blame corrected:** restoring the pre-H1 prototype
(`git show 4df7ac10:examples/psp_row_stream_roundtrip.rs`) gives the *same two errors at the same
two lines*, and `git cat-file -e main:examples/psp_row_stream_roundtrip.rs` fails — the file is
not on `main`. **H1 did not cause the red.** What H1 did was reason about this file's lint status
and put the suppression at the `mod` declaration, which covers one of the two targets; and its
report claimed the include "puts the prototype in the clippy gate for the first time", which is a
wrong *mechanism* claim about a gate that had been failing for four milestones.

### Majors

- **M1 — every witness the corpus minted was expressible by a two-number witness**, including the
  one the code called *the one a two-number witness could not express*. The hole's two runs sat on
  the two borders, so a codec keeping one prefix length and one suffix length reproduced all three
  shapes. The precondition named an implementation it did not exclude.
- **M2 — `..prototype::Scales::default()`** meant a field added to `Scales` would be quantised at
  the prototype's default while ng used its own, narrowing the cross-arm equality to `q_sum` with
  no compile error. Proved by adding a fourth field: the prototype's own two exhaustive literals
  were flagged, the harness's `..default()` site was not.
- **M3 — both comparison functions were hand-maintained field lists.** Neither destructured, so a
  field added to `SampleLocusObservations` or `SequenceObservation` goes uncompared with no
  compile error. B1 is that drift having already happened.
- **M4 — everything the store holds that is not a record was written and never read back.**
  Measured with defects in `src/ng/psp/`: a contig length one too long, a block index whose every
  first position was a base too far, and a trailer truncated by one byte **all passed** a
  100,000-record run.
- **M5 — the block-count precondition came from the writer's own tally, not from the file.**
- **M6 — an input `.psp` this build cannot read failed with the library's raw error**, with no
  path and no hint that the file predates the current column set. It cost one agent two rounds.
- **M7 — three bare `bool` literals** chose which *format* the oracle's store was written in.

### Minors and nits

`--label` documented nowhere; `report` asserting under a name that promises printing;
`write_the_ng_store` returning three same-typed counts positionally; `at` naming three different
indices; `CorpusShape`'s fields named for the thing counted rather than the count; the read-group
modulus and its tally array kept in sync by hand; `compare` as a placeholder name;
`note_the_drift` taking two transposable `&PileupRecord`s; the `#[allow]` comment saying "two"
over an attribute naming three; `--limit 0` reporting store corruption; flag `expect` messages of
one letter; the frozen `created` stamp with no stated reason; the prototype carrying no marker
that it is an oracle; two untested branches of `assert_the_corpus_can_fail`; the locus kind listed
under "on both pairs" when it is compared on one.

## 6. Out of scope observations

- **`src/ng/psp/` accepts a record whose `region` spans one base more than `reference_bases.len()`
  and reads it back faithfully.** Nothing in the writer or the reader requires the two to agree.
  Found while mutating the harness. This is a question for the psp module's contract, not for the
  harness, and it is why B1's span check had to be added on the *prototype* arm.
- **`examples/psp_row_stream_roundtrip.rs:307`** carries a dead store in the oracle's encoder.
  Left alone deliberately: the oracle's behaviour is not edited.
- **The duplicated production→ng mapping** shared with `examples/ng_psp_head_encoding.rs` is
  **partially justified**: the four-field policy difference is real and must stay, and the twelve
  identical lines around it are one thing written twice. Filed as a follow-up, not a merge
  condition.
